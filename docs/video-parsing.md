# 视频网页交互与原生接管

视频首次提取未得到正文地址时，详情页显示解析器正在使用的同一个 WKWebView，不另建阅读器、重新导航或丢弃页面状态。需要点击网页播放的站点仍需用户操作；这是继续使用已加载的网页，不保证所有站点可以静默自动提取。

页面可见期间继续观察当前站点规则的输出。正文地址就绪后，先暂停网页音视频，再交给原生播放器；如果正在查看原始网页，自动关闭该页并进入原生播放。重新打开完整视频网页也在同一 WebView 加载，避免用户操作了另一份文档而解析器仍停在旧文档。离开详情、取消观察或开始另一轮加载时，旧观察不能提交结果。

每次 JavaScript 提取都有超时。站点选择器、广告排除规则仍属于私有 `.site`，应用代码不包含站点域名、播放器 ID 或“六秒视频就是广告”的判断。规则需要明确区分正文播放器与广告播放器，不能扫描全页取第一个 MP4。

回归使用 localhost 和合成页面，覆盖正文在六秒后出现、取消并恢复观察、退出后的旧观察失效，以及实际 SwiftUI 详情页复用网页并启动 AVPlayer。六秒合成正文视频用于验证短片也可以正常接管，时长不会被当作广告标记。测试不证明特定真实站点在所有网络和账号状态下都能播放。
