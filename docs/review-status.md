# 审计修复与剩余工作

当前使用唯一的 `schemaVersion: 1` 和原 Cove 资料库。首页、封面、列表样式及现有功能应持续保留。

| 问题 | 当前实现 | 验证范围 |
| --- | --- | --- |
| TLS 证书绕过 | 删除信任所有证书的处理，使用系统验证 | 构建与代码检查 |
| 缩略图缓存路径穿越 | URL 哈希写入；已有缓存只允许安全路径读取 | 路径与符号链接测试 |
| CBZ/EPUB 路径逃逸 | 解包路径、容器与 manifest 引用边界；EPUB 内容禁用 JS | 路径测试；完整恶意文档夹具待补 |
| NAS 大文件整包读取 | 浏览和历史入口使用 SMB 视频/音频流；文档及非流式媒体直接下载到磁盘 | 合成大文件、读取分块与取消测试；真实 NAS 待测 |
| 分类过滤拖动排序 | 在全量排序中替换当前分类的槽位，保存唯一全局序号 | 分类交错与多选移动测试 |
| 标签与卡片手势重叠风险 | 标签使用独立 Button，播放/长按手势仅位于封面和文本区域 | iOS 26.3.1 localhost 对照中，原实现未复现双触发；新实现验证搜索与播放分别工作 |

NAS 编码图片内存读取最多 32 MiB，单次范围读取最多 512 KiB。磁盘下载上限为 500 MiB，读取前及下载过程中检查；取消或失败清理部分文件，完成后再发布。超出上限的非流式文件提示先保存到本地。文件名使用独立目录，避免同名覆盖。视频是否能播放仍取决于系统支持的编码。

## iPad 与 ATS

恢复显式 `UIRequiresFullScreen: false`。删除这个 false 不会自动变成 true，也不能据此判断退出多任务；启用 true 才会请求兼容模式。[Apple 说明](https://developer.apple.com/documentation/bundleresources/information-property-list/uirequiresfullscreen)。

删除多余的 `NSAllowsArbitraryLoads`，保留 `NSAllowsLocalNetworking: true`。在目标系统上，后者的存在本来就会使前者被忽略，删除不扩大网络许可。ATS 与 HTTPS 默认服务器信任评估是两层不同的检查。[Apple ATS 说明](https://developer.apple.com/documentation/bundleresources/information-property-list/nsapptransportsecurity/nsallowsarbitraryloads)。

## 外观与小说阅读

全局主题沿用原设置，支持跟随系统、浅色、深色和护眼黄；原生列表、设置、站点引导、音乐播放器及 TXT/EPUB/漫画阅读器共用主题。网页和 PDF 文档保留内容自身的配色。

TXT 支持左右翻页与上下滚动，设置持久化并进入配置备份。读取/编码转换/章节检测和排版在后台执行，过期排版结果不覆盖当前状态。切换模式、字体及再次打开恢复进度；本地和 NAS 入口更新原阅读记录。

EPUB 只在切换文档时加载页面，主题样式在加载完成后注入，外观变化不重载当前章节；内容脚本保持禁用。视频解析页限制封面背景宽度，长标题完整换行，内容超出时可滚动，取消按钮保持可见。

新增测试覆盖主题、文本完整性、滚动恢复/保存/模式与字体切换、EPUB 样式及文档位置、窄屏和大字体的视频加载布局，并检查对应截图。此处不代表 EPUB 跨章节恢复或完整图片管线已经完成。

## NAS 与网站布局切换

两边共用 `BrowserLayout`、右上角的 `BrowserLayoutMenu` 和 `BentoGrid`，提供列表、Bento、竖版。网站以配置为默认，手动选择按入口保存；NAS 选择按连接 UUID 与目录保存。切换布局不重新解析或拉取目录，保留原资源路由、选集、分类、分页和下载。默认图片流继续保留。

NAS 展示提取到独立组件，目录、文件与下载使用独立操作。已读索引按连接隔离并在记录变化时准备；显示条目分批追加。网站 parser 按配置变化刷新，Bento 分组按数量和列数变化准备。自动化验证覆盖偏好隔离、目录/文件行为、Bento 不漏项、三种布局、网站切换请求计数和导航/重开记忆；真实 NAS 图片加载和设备交互仍需现场回归。

## 标签和图片来源上下文

竖版视频卡片与 Bento 共用标签按钮；演员搜索与封面/标题的播放区域独立。搜索词作为一个 URL 参数编码。

列表、竖版、Bento、收藏和视频解析页传递图片所属定义及 Referer。镜像页面与 CDN 域名变化时，使用所属定义的图片转换规则；不增加站点域名或密钥硬编码。内存、磁盘和进行中的图片请求按 URL、所属定义、Referer 与转换参数指纹隔离，外观变化仍复用同一上下文的图片。只有无上下文的请求可读取旧的无签名缓存。

离线测试使用虚构域名和生成的加密 PNG，覆盖跨域转换归属、不同来源/Referer/规则修订的缓存隔离，以及解码与复用。真实网络样本的原有 AES 和系统 ImageIO 解码也已检查，样本及规则仍只放在本地忽略目录。

## 本地规则回归

新增 [站点样本测试](site-tests.md)：实际 `.site` 与保存的网页快照共同验证列表数量/顺序/链接、视频结果、下一页、AJAX 请求、门户和原始加密封面的解码。移除图片转换配置的对照会拒绝同一加密样本。私有样本位于 Git 忽略的 `config/site-tests/`，仅进入 XCTest；公开仓库保留运行器和虚构样本。

当前本地 8 份定义通过格式、脚本编译与往返检查；2 个站点具有共 9 个快照样本。其余规则仍缺少功能样本，测试会列出覆盖缺口。带私有目录时 57 项测试通过；无私有目录时 54 项通过、3 项明确跳过，公开样本继续验证运行器。测试还发现并修正了构建副本中陈旧的私有预置，实际规则未进入提交。
