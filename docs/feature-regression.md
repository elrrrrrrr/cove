# v2 功能退化对照

本对照比较重构前基线 bf99c97 与 v2 提交 8f2dace。恢复提交 0835a8d 已重新放回原功能视图。以下是代码对照结果，不等同于所有真实站点与设备已经完成验收。

## 原因

重构同时改了数据模型、存储目录、配置 schema 和全部主要视图。已有 HomeView、SiteGalleryView、VideoDetailView、ComicDetailView 等被新通用页面替换，而没有先定义必须保留的能力和同数据视觉基线。

配置转换脚本明确把 bento 映射成 grid；旧规则的 presentation 原本按页面定义，v2 折成来源级默认。旧 BookmarkSite 的 faviconData/备注/分类等没有对应的完整来源展示映射。新 Cove2 资料库也不读取原 Cove 库，因此旧收藏、历史和连接信息在新 UI 中不可见，文件并未删除。

49 项 v2 测试验证的是新实现能工作，没有验证新旧功能一致；没有覆盖原首页、Bento、分类工具、详情页面等回归。

## 已确认的删除或简化

| 范围 | v2 退化 |
| --- | --- |
| 首页 | 快速访问卡片改成文字来源列表；折叠分区和最近阅读 Bento 消失；首页只显示前 6 个来源 |
| 站点展示 | 站点 favicon、备注/分类展示未接入；旧缩略图缓存命名和路径不再使用。内容缩略图管线仍存在，但旧缓存没有衔接 |
| 列表与分类 | Bento 改普通等宽网格；按页面的呈现配置被折成来源默认；原分类选择器被转换成入口列表；页码跳转没有重做 |
| 漫画详情 | 封面、标签展示、原开始/继续阅读按钮与章节标记的完整详情结构被简化成列表；基本章节和阅读仍存在 |
| 网页操作 | 原浏览器的前进/后退、刷新、复制链接、Safari 打开、保存稍后再看没有完整保留；新页只保留基础浏览/分享等 |
| NAS 图片 | 目录内上一张/下一张、双击/捏合缩放及拖动，被单张图片展示替代 |
| 配置备份 | 原设置、站点备注/分类/单站覆盖及 NAS 配置的完整备份，被拆成来源备份和单独收藏导出；旧备份不再可直接导入 |
| 诊断 | 连接日志、当前列表的解析结果/请求状态/解析日志、视频解析诊断入口未完整重做 |
| 原数据 | 旧收藏、历史、站点和 NAS 连接信息不在 Cove2 里；旧库和 Keychain 没有清空，但新数据入口不读取 |

基本 CSS/JS 解析、搜索、加载更多、选集、收藏操作、SMB、音乐和 PDF/EPUB/TXT/CBZ 的基本打开能力仍在 v2。不能因此认为所有细分功能和交互已保留。

SiteTabsView 虽在重构中删除，但原基线没有调用入口，不能直接当作已经丢失的在用功能。PDF、TXT、EPUB 的细节交互及 NAS 视频行为还需要完整设备回归，不能凭文件存在宣布等价。

DSM/FnOS 是用户明确要求删除的能力，不属于本次意外功能退化。

## 恢复状态

原首页、站点/内容卡片、图库布局、漫画详情、网页工具、NAS 图片浏览、原配置备份和诊断代码已恢复；继续使用原 Cove 库。原库确认 8 个站点、203 条收藏和 1087 条历史仍在，并有本地备份。

恢复版真机 Release 构建/签名与 26 项单元测试通过。旧库副本的首页已在模拟器打开。elr-ip 断线，恢复包尚未安装，完整真机验收仍待设备连接。
