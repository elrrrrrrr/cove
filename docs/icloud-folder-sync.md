# iCloud Drive 文件夹同步

Cove 通过系统文件选择器授权访问指定文件夹，无需 CloudKit / iCloud Documents entitlement。适合免费个人开发签名和 SideStore。iCloud 空间订阅提供存储，不改变开发签名期限。

## 云端目录

```text
cove/
├── sites/
│   └── <id>.site       # 独立站点定义，schemaVersion 1，YAML
├── favorites.json     # 当前 schemaVersion 1 收藏格式
├── app-data.json      # 设置、站点入口、NAS、历史、离线索引和偏好
├── Files/             # 离线内容，存在离线文件时创建
├── Backups/           # 被更新/删除文件的恢复副本
└── Conflicts/         # 同时修改产生的冲突原文
```

只使用这一种分文件同步结构。`sites/*.site` 是站点定义来源，`favorites.json` 是收藏来源，`app-data.json` 不嵌入站点定义或收藏数据，不同时维护整包快照作为云端同步来源。每份配置均使用当前 schemaVersion 1。

`app-data.json` 是现有配置备份的其余字段，另含 `siteDefinitionIDs` 目录以确认所需文件已经齐全；完整文件夹组装成同一配置备份值进行校验和合并。只把它单独导入并不能恢复全部数据，恢复时应选择整个同步文件夹。独立「导出配置」继续产生完整的当前配置备份。

## 使用和修改

1. 手机「文件 → iCloud Drive」新建专用文件夹，例如 cove。
2. Cove「设置 → 云端同步 → iCloud Drive 文件夹」选择该文件夹。
3. 首次连接合并两端记录。同字段不同优先云端，并留存冲突副本。
4. 其他设备授权相同文件夹即可恢复数据，NAS 密码须重新输入。

可在 Mac 直接修改已有 `.site` 的解析规则、入口、匹配和转换参数，以及 `favorites.json` 的收藏数据，再打开手机上的 Cove 自动同步，无需重新构建。站点和入口 ID、收藏 UUID 保持稳定。修改站点入口的名称、地址及分类时，通过入口 ID 更新对应站点记录，保留书签 UUID、自定义名称和备注。

目录中的新增 `.site` 会加入解析配置库，不自动重建已删除的快速访问入口；入口请在 Cove 内管理。通过 Cove 删除站点定义时，也须清理相关入口。不要只把目录内预期的文件移走；`siteDefinitionIDs` 仍要求该文件时会暂停，避免把 iCloud 尚未下载误认为删除。手动删除需同时调整 `app-data.json` 中的站点目录和关联入口。删除收藏记录则在 `favorites.json` 中移除对应项，保留其他项的 ID。

项目私有 `sites/` 仅供首次安装导入，不是另一个同步来源。后续配置变更使用 iCloud 目录或 Cove 内的设置。

## 同步行为

前台打开应用、数据修改后以及前台每分钟尝试同步，可关闭自动同步改为手动。应用退出或进入后台不保证即时同步。界面仅显示「同步中…」「同步完成」等简短状态，失败时点「查看原因」查看详情。

「同步完成」表示 Cove 已写入文件提供器并保存本机记录，不代表已经读取服务器上传状态。换设备前检查「文件」中的状态，或在另一台设备查看这次更新。

本机 `Application Support/Cove/config/FolderSync/<folder-hash>/Baseline.json` 仅是上次同步的合并基线，不是第二个配置来源。按记录 ID 三方合并新增、修改和删除；不同字段独立修改可合并，同字段同时修改保留本地并备份双方。原文保存在 `Conflicts/<UUID>/`，系统暴露的 NSFileVersion 冲突版本也先备份、合并，再标记解决。

写入前备份将被修改的配置文件，app-data.json 最后发布；失败回滚本次新文件，缺文件、未知版本、重复 ID、路径逃逸、符号链接或损坏内容会暂停同步，不覆盖云端。站点文件内容未改变时保留原始格式和注释。断开保留全部数据；「清除所有数据」先断开，避免本机重置清空云端。

## 数据范围

- 站点定义、入口、快速访问、排序、备注和图标。
- 收藏、置顶、顺序、缩略图地址和原始标识。
- 阅读记录、进度、封面、关联站点和 NAS 标识。
- 主题、字号、行距、小说翻页、内容拦截开关、首页折叠及浏览布局。
- NAS 主机、端口、用户名、共享名和启用状态。
- Cove 管理的离线文件及元数据，包括小说、漫画、图片和音视频。

密码留在 Keychain。系统授权、文件夹书签、外部文件绝对路径、数据库、临时下载、可重建缓存和诊断日志不导出。NAS 上未下载的源文件不复制到云端。外部文件须先导入 Cove 离线库才能同步内容。

离线内容按 SHA-256 存于 `Files/<hash>`，流式校验及磁盘复制，单文件最大 100 GB，全部配置文档最多 64 MB。网页滚动回弹产生的本机负进度在导出时归零，网页视频播放秒数保留，不修改源记录或生成新 ID。仅保存网页地址的条目不要求实际文件。备份、冲突和历史附件不会自动清理，避免其他设备尚未同步时丢失数据。

iCloud 负责数据。代码变化仍需 Xcode 构建 IPA，再交给 SideStore 安装；SideStore 完成首次配置后可在手机续签。系统授权、服务器上传及实际 SideStore 签名需在真实设备验证。
